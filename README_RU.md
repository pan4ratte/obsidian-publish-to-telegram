# Плагин Publish to Telegram

[English](https://github.com/pan4ratte/obsidian-publish-to-telegram/blob/main/README.md) | Русский

![](media/plugin-demo-settings.png)

Данный плагин позволяет постить заметки напрямую в каналы/группы Telegram с разными пресетами. Плагин работает через ваш персональный бот, отправляя ему содержимое активной заметки и информацию о целевом канале/группе. Поддерживается всё стандартное форматирование Telegram, а также прикрепление фото, альбомов и документов, плюс доступны некоторые расширенные настройки публикации.


## Фичи

1. Создавайте пресеты для публикации постов в разные каналы и группы.

2. Делайте посты разными способами: с помощью сочетаний клавиш, палитры команд и контекстных меню.

3. Прикрепляйте фото, видео, альбомы и документы к своим постам.

4. Используйте расширенные настройки публикации для того, чтобы:

    * Сделать пост сразу в несколько каналов/групп.
    * Сделать пост с уведомлением без звука.
    * Сделать пост с прикреплёнными медиа под текстом сообщения.
    * Отредактировать уже существующий пост.

5. Прикрепляйте к постам заготовленные комментарии, которые будут выложены после публикации записи в обсуждении.  

6. Устанавливайте пресет по умолчанию, чтобы быстро делать посты из палитры команд или с помощью сочетания клавиш.

7. Опционально включайте автоматическое сохранение ссылки на опубликованный пост в свойства заметки.

8. Открывайте справку по использованию плагина в его настройках или из палитры команд.


## Инструкции по установке

Пока плагин не появился в официальном магазине Obsidian, проще всего установить его через плагин `BRAT`:

1. Из официального магазина плагинов Obsidian установите плагин `BRAT`.

2. В настройках `BRAT` найдите раздел "Beta plugin list" и нажмите на кнопку "Add beta plugin".

3. В появившемся окне вставьте ссылку на репозиторий плагина `Publish to Telegram`: [https://github.com/pan4ratte/obsidian-publish-to-telegram](https://github.com/pan4ratte/obsidian-publish-to-telegram)

4. В пункте "Select a version" выберите вариант "Latest version" и нажмите на кнопку "Add plugin".

Готово! Плагин автоматически установится и будет готов для использования.


## Использование

### Пресеты

Для пубикации заметок в Telegram необходимо настроить пресет.

1. С помощью официального инструмента Telegram [@BotFather](https://t.me/BotFather) создайте свой личный бот, следуя инструкциям в приложении. Если вы планируете делать посты в группу или выкладывать заготовленные комментарии под постами, в настройках бота перейдите в меню "Bot Settings" и в секции "Groups and Channels" выключите опцию "Group Privacy".

2. Скопируйте ключ API вашего бота в приложении и вставьте его в поле **Токен бота** вверху настроек плагина, затем нажмите **Сохранить**. Токен хранится защищённо во встроенном хранилище ключей Obsidian (SecretStorage), а не в открытом виде. Вы можете удалить его в любой момент кнопкой **Удалить**.

3. С помощью инструмента [@userinfobot](https://t.me/userinfobot) узнайте ID канала/группы, куда вы планируете выкладывать публикации. Вы также можете узнать ID своего аккаунта, если хотите использовать пресет для отправки сообщений себе (бот будет отравлять вам личные сообщения — не забудьте перед этим начать переписку с ботом).

4. Скопируйте ID целевого канала/группы и вставьте его в соответствующее поле в настройках плагина. Альтернативно, если постинг делается в *публичный* канал, вы можете вставить это поле ссылку на канал в формате `@channel_name`.

5. Находясь в Telegram, добавьте созданного вами бота в целевой канал/группу и назначьте ему роль администратора. Дайте боту разрешение только на публикацию сообщений.

Теперь вы сможете публиковать заметки в Telegram, используя имя вашего пресета через палитру команд или с помощью контекстного меню заметки.

### Маркеры содержимого

Вы можете публиковать только определённую часть заметки с помощью **маркеров начала и конца**. В Telegram будет отправлен только текст между маркерами.

Маркеры по умолчанию:
- Маркер начала: `:::post-start-here`
- Маркер конца: `:::post-end-here`

Вы можете задать собственные маркеры глобально в настройках плагина или переопределить их для каждого пресета. Если маркеры не найдены в заметке, публикуется всё содержимое.

### Вложения

Поддерживаются вложения в виде медиа, альбомов (групп медиа) и документов. Чтобы прикрепить файл к посту, используйте синтаксис любой из стандартных опций встраивания в Obsidian:

`![[файл-какой-то-книги.pdf]]`

`![](файл-какой-то-картинки.jpg)`

`!(файл-какого-то-видео.mp4)[]`

Также, вы можете встраивать внешние файлы из интернета:

`![](https://obsidian.md/картинка.png)`

Форматы, поддерживаемые на данный момент:

| Расширение                                         | Тип вложения    |
| -------------------------------------------------- | --------------- |
| `.jpg`, `.jpeg`, `.png`, `.webp`                   | Фото / Альбом   |
| `.gif`                                             | Анимация        |
| `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`            | Видео / Альбом  |
| `.pdf`                                             | Документ        |

### Комментарии

Вы можете заготовить один или несколько комментариев для вашего поста, которые появятся в обсуждении сразу после его публикации. Для использования этой опции:

1. В настройках плагина включите функцию "Считать .md-вложения комментариями к посту".

2. Если комментарий к посту будет опубликован на канале, то к каналу должен быть привязан чат с обсуждениями, а бот должен быть добавлен в этот чат с правами администратора. Если комментарий к посту будет опубликован в группе, то он отобразится как обычный ответ на сообщение.

3. Чтобы заготовить комментарий к посту, используйте синтаксис встраивания `![[файл-комментария]]`. Только файлы с расширением .md считаются комментариями.

Обратите внимание, что комментарии публикуются с небольшой задержкой.

### Расширенные настройки публикации

Вы можете вызывать окно расширенных настроек публикации через палитру команд (`Ctrl + P`), введя "Publish to Telegram: Опубликовать с расширенными настройками". В этом окне настроек вы можете:

* Сделать пост сразу в несколько каналов/групп.
* Сдлеать пост с уведомлением без звука.
* Сделать пост с прикреплёнными медиа под текстом сообщения.
* Отредактировать уже существующий пост. Ссылки на посты хранятся в свойстве `telegram_links`, которое заполняется автоматически если включена соответствующая функция в настройках, а также его можно создать и заполнить вручную.

### Лимиты

Стандартные лимиты для постов в Telegram применяются к лимитам на количество символов на пост, лимитам по размерам прикреплённых файлов на пост, и т.д. Больше об этом: [https://limits.tginfo.me/](https://limits.tginfo.me/)
