%%
Методы: "Аккаунт + rich-text" и "Бот + rich-text".

Ожидается: одна пустая строка между абзацами — обычный отступ абзаца; каждая следующая пустая строка — видимая пустая строка в сообщении. Внутри блока кода пустые строки не меняются.
%%

Абзац, после которого одна пустая строка.

Абзац, после которого две пустые строки.


Абзац, после которого три пустые строки.



Последний абзац.

```
код

с пустыми


строками
```
