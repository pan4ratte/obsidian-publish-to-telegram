%%
Методы: "Аккаунт + rich-text" и "Бот + rich-text".

Шаги: под строкой "Вставьте элементы сюда" вставьте через подменю "Rich-text форматирование" каждый элемент — аккордеон, цитату по центру (с автором и без), ссылку на почту, ссылку на сноску и текст сноски, нижний колонтитул, верхний и нижний индекс, формулу, медиа с подписью, карту, коллаж и слайдшоу. Для индексов и формулы сначала выделите слово — элемент должен обернуть выделенный текст.

Ожидается: каждый вставленный элемент правильно отображается в опубликованном сообщении.
%%

Вставьте элементы сюда: слово для индекса, слово для формулы.
