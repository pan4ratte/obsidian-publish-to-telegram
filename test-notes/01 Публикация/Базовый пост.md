Простой пост для проверки самой публикации. Опубликуйте его каждым способом и отмечайте здесь.

Методы:
- [ ] "Аккаунт"
- [ ] "Аккаунт + rich-text" (без Telegram Premium — ошибка про Premium)
- [ ] "Бот"
- [ ] "Бот + rich-text"

Целевые чаты:
- [ ] Канал
- [ ] Группа
- [ ] Тема в группе: из списка, в формате `ID/номер темы` и ссылкой на тему
- [ ] Личные сообщения
- [ ] Несколько чатов в одном пресете
- [ ] Чат, введённый вручную через `@username` или `ID`

Способы запуска:
- [ ] Сочетание клавиш пресета по умолчанию (если его нет — открываются расширенные настройки)
- [ ] Палитра команд: "Опубликовать в …" для каждого пресета
- [ ] Контекстное меню файла: "Опубликовать в Telegram"
- [ ] Расширенные настройки: несколько пресетов сразу, а также метод, отличный от метода пресета
- [ ] Расширенные настройки: секция "Публикация без пресета"

Аккаунты и боты:
- [ ] Пресеты с разными аккаунтами публикуют каждый от своего аккаунта
- [ ] Пресеты с разными ботами публикуют каждый от своего бота
- [ ] Без авторизации — ошибка "Перед публикацией авторизуйтесь в Telegram…"

Ожидается: пост приходит во все выбранные чаты, ссылки на него записываются в свойство `tg_posts`.
%%
