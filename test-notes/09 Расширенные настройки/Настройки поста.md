Методы: "Аккаунт" и "Бот".

Проверьте по очереди — у поста и у комментария:
- [ ] Без звука: сообщение приходит без уведомления. Опция "Публиковать без звука по умолчанию" включает это для всех постов.
- [ ] Вложения под текстом: фото под текстом. В rich-text методах кнопка неактивна.
- [ ] Отправить, когда получатель появится в сети: только методы аккаунта.
- [ ] Отложенная публикация: только методы аккаунта. У комментария даты нет — он уходит вместе с постом.
- [ ] "Комментарии повторяют настройки поста": настройка, изменённая у поста, повторяется у комментария; настройка, изменённая у самого комментария, остаётся своей.
%%
