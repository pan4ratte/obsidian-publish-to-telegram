Методы: все четыре.

В меню расширенной публикации выберите пресет или заполните поле "Публикация без пресета" (автор, метод, чат). У каждого поста в ряду кнопок настроек есть кнопка ответа (иконка облачка со стрелкой).

Проверьте по очереди:
- [ ] Поле "Публикация без пресета" больше не превращает ссылку на сообщение в плашку ответа: вставка ссылки — просто текст, Enter добавляет обычную плашку чата (для `t.me/c/…/тема/сообщение` — плашку темы).
- [ ] Кнопка ответа открывает под собой плавающее поле для ссылки с кнопкой-галочкой "Готово" (не отдельное окно, без текста описания), курсор сразу в поле. Подсказка у кнопки: "Ответить на сообщение".
- [ ] Поле стоит по центру под кнопкой; у кнопок у края меню (и на телефоне) оно сдвигается, но не выходит за границы меню публикации.
- [ ] Не ссылка на сообщение (`@username`, `https://t.me/канал`) + Enter или "Готово" — под полем появляется красное "Это не ссылка на сообщение.", поле не закрывается; при вводе текста надпись исчезает.
- [ ] Enter, "Готово" и клик мимо поля сохраняют ссылку; Escape закрывает только поле (меню публикации остаётся открытым) и ничего не меняет. Клик мимо с неверной ссылкой просто закрывает поле. Повторное нажатие на кнопку закрывает поле, а не открывает его заново.
- [ ] При прокрутке меню поле едет вместе с кнопкой.
- [ ] После сохранения кнопка подсвечена, подсказка — "Ответ на сообщение 123 в …": сначала ID чата, через мгновение — название (если чат доступен одному из аккаунтов). Поле открывается с сохранённой ссылкой; очищенное поле + Enter снимает ответ.
- [ ] Ответ в том же чате: ссылка на сообщение из чата, куда идёт пост. Пост 1 приходит ответом на него, пост 2 (без ответа) — обычным постом.
- [ ] Ответ в другой чат: ссылка на сообщение из другого канала или группы. Пост 1 публикуется в выбранный чат и показывает цитату сообщения из другого чата; нажатие на цитату ведёт к нему.
- [ ] Ответы у разных постов: задайте ответ и посту 2 (на другое сообщение) — каждый пост отвечает на своё.
- [ ] Сообщение в теме форума (`t.me/c/…/тема/сообщение`), пост в ту же группу без темы в цели — пост приходит ответом внутри этой темы.
- [ ] Комментарий и пост в режиме "Пропустить" или "Редактировать" — кнопка ответа неактивна.
